# icopia — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App de bandeja para Windows que copia todos los originales de iCloud Fotos a una carpeta local organizada `AAAA\AAAA-MM\`, verifica cada archivo y, con confirmación explícita, borra de iCloud solo lo verificado.

**Architecture:** Un crate Rust (`icopia/`) con una biblioteca y dos binarios: `icopia.exe` (CLI de consola) e `icopia-bandeja.exe` (icono de bandeja). Rust hace registro SQLite, descargas reanudables, verificación, organización y borrado seguro. Un proceso Python pequeño (`puente/puente_icloud.py`, empaquetado como `puente-icloud.exe`) usa la librería `pyicloud_ipd` de icloudpd **v1.33.0** solo para iniciar sesión, listar y borrar en iCloud; se comunican con JSON por líneas (stdin/stdout).

**Tech Stack:** Rust 1.93 (edition 2021), rusqlite (bundled), reqwest blocking + rustls, sha2, chrono, serde, tao + tray-icon, rfd, tauri-winrt-notification, winreg, windows-sys. Python 3.11 + icloudpd 1.33.0 (desde git) + PyInstaller + pytest.

**Spec:** `docs/superpowers/specs/2026-11-07-icopia-design.md`

## Hechos verificados que el plan da por buenos (leídos del código de icloudpd v1.33.0)

- `PyiCloudService("com", apple_id, password_provider, cookie_directory=...)` autentica en el constructor. Con sesión guardada no necesita contraseña; si falta y `password_provider()` devuelve `None`, lanza `PyiCloudFailedLoginException`.
- 2FA: `api.requires_2fa` / `api.requires_2sa`; `api.validate_2fa_code(code) -> bool` (también confía la sesión).
- Bibliotecas: `api.photos.private_libraries` → `{nombre_zona: PhotoLibrary}` con `"PrimarySync"` (personal) y `"SharedSync-…"` (Fototeca Compartida). Iterar `lib.all` da `PhotoAsset`.
- `PhotoAsset`: `.id`, `.calculate_filename()` (puede ser `None`), `.item_type` (`AssetItemType.IMAGE|MOVIE`), `.item_type_extension`, `.asset_date`, `.has_asset_date`, `.added_date`, `.versions` → `{AssetVersionSize.ORIGINAL|ADJUSTED|…, LivePhotoVersionSize.ORIGINAL|…: AssetVersion(size, url, type, checksum)}`. `._asset_record["fields"]` contiene `"resJPEGFullRes"` solo si la foto está editada.
- `filename_with_fallback(asset_id, ext)(None)` genera un nombre de respaldo.
- icloudpd descarga con `Range: bytes=N-` (reanudable). Borrar = POST a `{lib.service_endpoint}/records/modify?{urlencode(lib.params)}` con `isDeleted: 1`, `recordChangeTag` y `recordName` del `_asset_record` y `zoneID: lib.zone_id`. Lo borrado va a "Eliminado recientemente".
- El wheel de PyPI de icloudpd trae solo un binario compilado: hay que instalar desde `git+https://github.com/icloud-photos-downloader/icloud_photos_downloader@v1.33.0`.

**Supuesto pendiente de validar con la cuenta real (Tarea 6, punto de control 1):** las `downloadURL` funcionan sin cookies desde Rust y responden `206` a `Range`. Si fallara, **parar** y rediseñar la descarga antes de seguir.

## Desviaciones menores respecto al spec

- Estados persistidos: `pendiente | verificado | error` (el paso "descargado" es transitorio dentro de una misma operación: descarga → verificación → renombrado → `verificado`).
- "Liberar espacio…" e "Iniciar sesión…" abren una **ventana de consola** (`icopia.exe liberar|login`) en vez de un diálogo gráfico propio: misma información, mismo `BORRAR`, mucho menos código frágil.
- Los vídeos editados se copian solo en su versión original (iCloud no expone la edición de vídeo con la misma clave).

```python
"""puente-icloud: puente JSON por líneas entre icopia (Rust) e iCloud Fotos.

Usa la librería pyicloud_ipd de icloudpd v1.33.0. Una petición JSON por línea en stdin;
respuestas JSON por línea en stdout. Todo lo demás (logs) va a stderr.

Peticiones:
  {"cmd":"sesion"}                       -> {"ok":true}
  {"cmd":"login","password":"..."}       -> {"ok":true,"requiere_2fa":bool}
  {"cmd":"codigo_2fa","codigo":"123456"} -> {"ok":true} | {"ok":false,"error":"codigo_incorrecto"}
  {"cmd":"listar"}                       -> {"asset":{...}}* {"aviso":"..."}* {"ok":true,"total":N,"omitidos":M}
  {"cmd":"borrar","ids":[...]}           -> {"ok":true,"borrados":[...],"fallidos":[{"id":..,"error":..}]}
Errores: {"ok":false,"error":"sesion_caducada"|"credenciales"|"otro","detalle":"..."}
"""
from __future__ import annotations

import argparse
import io
import json
import logging
import os
import sys
import traceback
import urllib.parse
from typing import Any, Callable, Dict, List, Optional, Tuple

from pyicloud_ipd.asset_version import ITEM_TYPE_EXTENSIONS
from pyicloud_ipd.base import PyiCloudService
from pyicloud_ipd.exceptions import PyiCloudAPIResponseException, PyiCloudFailedLoginException
from pyicloud_ipd.item_type import AssetItemType
from pyicloud_ipd.services.photos import filename_with_fallback
from pyicloud_ipd.version_size import AssetVersionSize, LivePhotoVersionSize
from tzlocal import get_localzone

BIBLIOTECA_PERSONAL = "PrimarySync"

_salida: Any = None  # se fija en main(); las pruebas lo sustituyen


class SesionCaducada(Exception):
    pass


class Credenciales(Exception):
    pass


def responder(obj: Dict[str, Any]) -> None:
    _salida.write(json.dumps(obj) + "\n")
    _salida.flush()


def extension_de(uti: str, nombre: str) -> str:
    if uti in ITEM_TYPE_EXTENSIONS:
        return ITEM_TYPE_EXTENSIONS[uti]
    ext = os.path.splitext(nombre)[1][1:]
    return ext.upper() if ext else "BIN"


def fecha_de(asset: Any) -> str:
    if asset.has_asset_date:
        dt = asset.asset_date
    else:
        try:
            dt = asset.added_date
        except (KeyError, TypeError, ValueError):
            dt = asset.asset_date
    return dt.astimezone(get_localzone()).isoformat()


def _parte(tipo: str, version: Any, extension: str) -> Dict[str, Any]:
    return {"tipo": tipo, "tamano": int(version.size), "url": version.url,
            "extension": extension, "checksum": version.checksum or ""}


def asset_a_json(asset: Any, biblioteca: str) -> Optional[Dict[str, Any]]:
    versiones = asset.versions
    original = versiones.get(AssetVersionSize.ORIGINAL)
    if original is None:
        return None
    nombre = filename_with_fallback(asset.id, asset.item_type_extension)(asset.calculate_filename())
    partes = [_parte("original", original, extension_de(original.type, nombre))]
    if asset.item_type == AssetItemType.IMAGE:
        live = versiones.get(LivePhotoVersionSize.ORIGINAL)
        if live is not None:
            partes.append(_parte("live", live, "MOV"))
        if "resJPEGFullRes" in asset._asset_record.get("fields", {}):
            editada = versiones.get(AssetVersionSize.ADJUSTED)
            if editada is not None:
                partes.append(_parte("editada", editada, extension_de(editada.type, nombre)))
    return {"id": asset.id, "biblioteca": biblioteca,
            "nombre_base": os.path.splitext(nombre)[0], "fecha": fecha_de(asset),
            "partes": partes}


def borrar_en_icloud(lib: Any, asset: Any) -> Optional[str]:
    """Manda el asset a 'Eliminado recientemente'. Devuelve None si fue bien o un código de error."""
    url = f"{lib.service_endpoint}/records/modify?{urllib.parse.urlencode(lib.params)}"
    datos = json.dumps({
        "atomic": True,
        "desiredKeys": ["isDeleted"],
        "operations": [{
            "operationType": "update",
            "record": {
                "fields": {"isDeleted": {"value": 1}},
                "recordChangeTag": asset._asset_record["recordChangeTag"],
                "recordName": asset._asset_record["recordName"],
                "recordType": "CPLAsset",
            },
        }],
        "zoneID": lib.zone_id,
    })
    try:
        respuesta = lib.session.post(url, data=datos, headers={"Content-type": "application/json"})
    except PyiCloudAPIResponseException as e:
        if e.code == "TRY_AGAIN_LATER":
            return "reintentar"
        raise
    try:
        cuerpo = respuesta.json()
    except ValueError:
        cuerpo = {}
    for registro in cuerpo.get("records", []):
        if "serverErrorCode" in registro:
            return str(registro["serverErrorCode"])
    return None


def es_error_de_sesion(e: Exception) -> bool:
    codigo = str(getattr(e, "code", "") or "")
    return codigo in ("401", "421", "AUTHENTICATION_FAILED") or "Authentication required" in str(e)


class Puente:
    def __init__(self, apple_id: str, cookies: str,
                 fabrica: Optional[Callable[[Optional[str]], Any]] = None,
                 borrador: Optional[Callable[[Any, Any], Optional[str]]] = None) -> None:
        self.apple_id = apple_id
        self.cookies = cookies
        self.api: Any = None
        self.cache: Dict[str, Tuple[str, Any, Any]] = {}
        self._fabrica = fabrica or self._fabrica_real
        self._borrador = borrador or borrar_en_icloud

    def _fabrica_real(self, password: Optional[str]) -> Any:
        return PyiCloudService("com", self.apple_id, lambda: password, cookie_directory=self.cookies)

    def conectar(self, password: Optional[str] = None) -> Any:
        try:
            return self._fabrica(password)
        except PyiCloudFailedLoginException as e:
            if password is None:
                raise SesionCaducada() from e
            raise Credenciales(str(e)) from e

    def api_lista(self) -> Any:
        if self.api is None:
            api = self.conectar()
            if api.requires_2fa or api.requires_2sa:
                raise SesionCaducada()
            self.api = api
        return self.api

    def bibliotecas(self) -> List[Tuple[str, Any]]:
        fotos = self.api_lista().photos
        libs = [(n, l) for n, l in fotos.private_libraries.items()
                if n == BIBLIOTECA_PERSONAL or n.startswith("SharedSync-")]
        if not any(n == BIBLIOTECA_PERSONAL for n, _ in libs):
            libs.insert(0, (BIBLIOTECA_PERSONAL, fotos))
        return libs

    def manejar(self, p: Dict[str, Any]) -> None:
        cmd = p.get("cmd")
        if cmd == "sesion":
            self.api_lista()
            responder({"ok": True})
        elif cmd == "login":
            self.api = None
            self.api = self.conectar(str(p["password"]))
            responder({"ok": True,
                       "requiere_2fa": bool(self.api.requires_2fa or self.api.requires_2sa)})
        elif cmd == "codigo_2fa":
            if self.api is None:
                raise SesionCaducada()
            if self.api.validate_2fa_code(str(p["codigo"])):
                responder({"ok": True})
            else:
                responder({"ok": False, "error": "codigo_incorrecto"})
        elif cmd == "listar":
            self.listar()
        elif cmd == "borrar":
            self.borrar(list(p.get("ids", [])))
        else:
            responder({"ok": False, "error": "otro", "detalle": f"comando desconocido: {cmd}"})

    def listar(self) -> None:
        self.cache = {}
        total = 0
        omitidos = 0
        for nombre, lib in self.bibliotecas():
            for asset in lib.all:
                try:
                    j = asset_a_json(asset, nombre)
                except Exception as e:  # un asset raro no debe tumbar el listado
                    omitidos += 1
                    logging.exception("asset omitido")
                    responder({"aviso": f"asset {getattr(asset, 'id', '?')} omitido: {e}"})
                    continue
                if j is None:
                    omitidos += 1
                    continue
                self.cache[asset.id] = (nombre, lib, asset)
                total += 1
                responder({"asset": j})
        responder({"ok": True, "total": total, "omitidos": omitidos})

    def borrar(self, ids: List[str]) -> None:
        borrados: List[str] = []
        fallidos: List[Dict[str, str]] = []
        for i in ids:
            entrada = self.cache.get(i)
            if entrada is None:
                fallidos.append({"id": i, "error": "no_listado"})
                continue
            biblioteca, lib, asset = entrada
            if biblioteca != BIBLIOTECA_PERSONAL:
                fallidos.append({"id": i, "error": "biblioteca_compartida"})
                continue
            error = self._borrador(lib, asset)
            if error:
                fallidos.append({"id": i, "error": error})
            else:
                borrados.append(i)
        responder({"ok": True, "borrados": borrados, "fallidos": fallidos})
```

```rust
        }
        for a in self.assets.clone() {
            if !en_asset(a) {
                return Err(ErrorFuente::Cancelado);
            }
        }
        Ok(self.assets.len())
    }

    fn borrar(&mut self, ids: &[String]) -> Result<ResultadoBorrado, ErrorFuente> {
        if self.sesion_caducada {
            return Err(ErrorFuente::SesionCaducada);
        }
        let mut r = ResultadoBorrado::default();
        for id in ids {
            if self.rechazar.contains(id) {
                r.fallidos.push((id.clone(), "reintentar".into()));
            } else {
                self.borrados.push(id.clone());
                self.assets.retain(|a| &a.id != id);
                r.borrados.push(id.clone());
            }
        }
        Ok(r)
    }
```

```rust
//! Cliente del proceso puente-icloud (Python): JSON por líneas sobre stdin/stdout.
use crate::fuente::{ErrorFuente, FuenteIcloud, ResultadoBorrado};
use crate::modelo::AssetIcloud;
use serde_json::{json, Value};
use std::io::{BufRead, BufReader, Write};
use std::path::Path;
use std::process::{Child, ChildStdin, ChildStdout, Command, Stdio};

pub struct Puente {
    hijo: Child,
    entrada: ChildStdin,
    salida: BufReader<ChildStdout>,
}

/// `ICOPIA_PUENTE` (ruta a .exe o .py; con .py usa `ICOPIA_PYTHON` o `python`)
/// o, si no, `puente-icloud.exe` junto al ejecutable actual.
pub fn comando_puente() -> anyhow::Result<Command> {
    if let Ok(ruta) = std::env::var("ICOPIA_PUENTE") {
        if ruta.to_lowercase().ends_with(".py") {
            let python = std::env::var("ICOPIA_PYTHON").unwrap_or_else(|_| "python".into());
            let mut c = Command::new(python);
            c.arg("-I").arg(ruta);
            return Ok(c);
        }
        return Ok(Command::new(ruta));
    }
    let exe = std::env::current_exe()?;
    let junto = exe.with_file_name("puente-icloud.exe");
    anyhow::ensure!(junto.exists(), "No encuentro puente-icloud.exe junto a {}", exe.display());
    Ok(Command::new(junto))
}

fn comprobar(v: &Value) -> Result<(), ErrorFuente> {
    if v["ok"].as_bool() == Some(true) {
        return Ok(());
    }
    let error = v["error"].as_str().unwrap_or("otro").to_string();
    let detalle = v["detalle"].as_str().unwrap_or("").to_string();
    Err(match error.as_str() {
        "sesion_caducada" => ErrorFuente::SesionCaducada,
        "credenciales" | "codigo_incorrecto" => ErrorFuente::Credenciales(format!("{error} {detalle}").trim().to_string()),
        _ => ErrorFuente::Otro(if detalle.is_empty() { error } else { detalle }),
    })
}

impl Puente {
    pub fn iniciar(apple_id: &str, dir_sesion: &Path, log: &Path) -> anyhow::Result<Puente> {
        Self::iniciar_con(comando_puente()?, apple_id, dir_sesion, log)
    }

    pub fn iniciar_con(mut cmd: Command, apple_id: &str, dir_sesion: &Path, log: &Path) -> anyhow::Result<Puente> {
        std::fs::create_dir_all(dir_sesion)?;
        if let Some(p) = log.parent() {
            std::fs::create_dir_all(p)?;
        }
        let stderr = std::fs::OpenOptions::new().create(true).append(true).open(log)?;
        cmd.arg("--cookies")
            .arg(dir_sesion)
            .arg("--apple-id")
            .arg(apple_id)
            .stdin(Stdio::piped())
            .stdout(Stdio::piped())
            .stderr(Stdio::from(stderr));
        #[cfg(windows)]
        {
            use std::os::windows::process::CommandExt;
            cmd.creation_flags(0x0800_0000); // CREATE_NO_WINDOW
        }
        let mut hijo = cmd.spawn().map_err(|e| anyhow::anyhow!("no pude lanzar el puente: {e}"))?;
        let entrada = hijo.stdin.take().expect("stdin del puente");
        let salida = BufReader::new(hijo.stdout.take().expect("stdout del puente"));
        Ok(Puente { hijo, entrada, salida })
    }

    fn enviar(&mut self, v: &Value) -> Result<(), ErrorFuente> {
        let mut linea = v.to_string();
        linea.push('\n');
        self.entrada
            .write_all(linea.as_bytes())
            .and_then(|_| self.entrada.flush())
            .map_err(|e| ErrorFuente::Otro(format!("no puedo escribir al puente: {e}")))
    }

    fn leer(&mut self) -> Result<Value, ErrorFuente> {
        let mut linea = String::new();
        let n = self
            .salida
            .read_line(&mut linea)
            .map_err(|e| ErrorFuente::Otro(format!("no puedo leer del puente: {e}")))?;
        if n == 0 {
            return Err(ErrorFuente::Otro("el puente terminó inesperadamente (ver puente.log)".into()));
        }
        serde_json::from_str(&linea).map_err(|e| ErrorFuente::Otro(format!("respuesta inválida del puente: {e}: {linea}")))
    }

    pub fn sesion(&mut self) -> Result<(), ErrorFuente> {
        self.enviar(&json!({"cmd": "sesion"}))?;
        comprobar(&self.leer()?)
    }

    /// Devuelve `true` si además hace falta el código 2FA.
    pub fn login(&mut self, password: &str) -> Result<bool, ErrorFuente> {
        self.enviar(&json!({"cmd": "login", "password": password}))?;
        let v = self.leer()?;
        comprobar(&v)?;
        Ok(v["requiere_2fa"].as_bool().unwrap_or(false))
    }

    pub fn codigo_2fa(&mut self, codigo: &str) -> Result<(), ErrorFuente> {
        self.enviar(&json!({"cmd": "codigo_2fa", "codigo": codigo}))?;
        comprobar(&self.leer()?)
    }
}

impl FuenteIcloud for Puente {
    fn listar(&mut self, en_asset: &mut dyn FnMut(AssetIcloud) -> bool) -> Result<usize, ErrorFuente> {
        self.enviar(&json!({"cmd": "listar"}))?;
        loop {
            let v = self.leer()?;
            if let Some(a) = v.get("asset") {
                let asset: AssetIcloud = serde_json::from_value(a.clone())
                    .map_err(|e| ErrorFuente::Otro(format!("asset inválido del puente: {e}")))?;
                if !en_asset(asset) {
                    let _ = self.hijo.kill();
                    return Err(ErrorFuente::Cancelado);
                }
                continue;
            }
            if v.get("aviso").is_some() {
                continue;
            }
            comprobar(&v)?;
            return Ok(v["total"].as_u64().unwrap_or(0) as usize);
        }
    }

    fn borrar(&mut self, ids: &[String]) -> Result<ResultadoBorrado, ErrorFuente> {
        self.enviar(&json!({"cmd": "borrar", "ids": ids}))?;
        let v = self.leer()?;
        comprobar(&v)?;
        let borrados = v["borrados"]
            .as_array()
            .map(|a| a.iter().filter_map(|x| x.as_str().map(String::from)).collect())
            .unwrap_or_default();
        let fallidos = v["fallidos"]
            .as_array()
            .map(|a| {
                a.iter()
                    .map(|x| (x["id"].as_str().unwrap_or("").to_string(), x["error"].as_str().unwrap_or("").to_string()))
                    .collect()
            })
            .unwrap_or_default();
        Ok(ResultadoBorrado { borrados, fallidos })
    }
}

impl Drop for Puente {
    fn drop(&mut self) {
        let _ = self.hijo.kill();
        let _ = self.hijo.wait();
    }
}
```

```rust
//! Dónde va cada archivo: <destino>\AAAA\AAAA-MM\<nombre>.
use crate::modelo::TipoParte;
use chrono::{DateTime, Datelike, FixedOffset};

pub fn sanear(nombre: &str) -> String {
    let s: String = nombre
        .chars()
        .map(|c| if c.is_control() || r#"<>:"/\|?*"#.contains(c) { '_' } else { c })
        .collect();
    let s = s.trim().trim_end_matches('.').trim().to_string();
    if s.is_empty() { "sin_nombre".to_string() } else { s }
}

pub fn fecha(texto: &str) -> anyhow::Result<DateTime<FixedOffset>> {
    Ok(DateTime::parse_from_rfc3339(texto)?)
}

pub fn carpeta_relativa(f: &DateTime<FixedOffset>) -> String {
    format!("{:04}\\{:04}-{:02}", f.year(), f.year(), f.month())
}

pub fn mes_clave(f: &DateTime<FixedOffset>) -> String {
    format!("{:04}-{:02}", f.year(), f.month())
}

pub fn sufijo_de_id(id: &str) -> String {
    id.chars().filter(|c| c.is_ascii_alphanumeric()).take(6).collect::<String>().to_lowercase()
}

pub fn nombre_parte(nombre_base: &str, tipo: TipoParte, extension: &str, sufijo: Option<&str>) -> String {
    let base = sanear(nombre_base);
    let base = match sufijo {
        Some(s) => format!("{base} ({s})"),
        None => base,
    };
    let ext = sanear(extension).to_uppercase();
    match tipo {
        TipoParte::Editada => format!("{base} (editada).{ext}"),
        _ => format!("{base}.{ext}"),
    }
}

/// Ruta relativa libre para una parte. `ocupada(clave_en_minusculas)` dice si ya existe.
pub fn elegir_ruta(
    nombre_base: &str,
    id: &str,
    fecha_txt: &str,
    tipo: TipoParte,
    extension: &str,
    ocupada: &mut dyn FnMut(&str) -> bool,
) -> anyhow::Result<String> {
    let carpeta = carpeta_relativa(&fecha(fecha_txt)?);
    let simple = format!("{carpeta}\\{}", nombre_parte(nombre_base, tipo, extension, None));
    if !ocupada(&simple.to_lowercase()) {
        return Ok(simple);
    }
    let sufijo = sufijo_de_id(id);
    let con_sufijo = format!("{carpeta}\\{}", nombre_parte(nombre_base, tipo, extension, Some(&sufijo)));
    if !ocupada(&con_sufijo.to_lowercase()) {
        return Ok(con_sufijo);
    }
    for n in 2..1000 {
        let s = format!("{sufijo}-{n}");
        let c = format!("{carpeta}\\{}", nombre_parte(nombre_base, tipo, extension, Some(&s)));
        if !ocupada(&c.to_lowercase()) {
            return Ok(c);
        }
    }
    anyhow::bail!("no encuentro un nombre libre para {nombre_base}")
}
```

```rust
//! Verificación: tamaño exacto + estructura completa + SHA-256 releído del disco.
use sha2::{Digest, Sha256};
use std::fmt;
use std::fs::File;
use std::io::{Read, Seek, SeekFrom};
use std::path::Path;

#[derive(Debug, Clone, PartialEq)]
pub enum FalloVerificacion {
    NoExiste,
    Tamano { esperado: u64, real: u64 },
    Estructura(String),
    Lectura(String),
}

impl fmt::Display for FalloVerificacion {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            FalloVerificacion::NoExiste => write!(f, "el archivo no existe"),
            FalloVerificacion::Tamano { esperado, real } => write!(f, "tamaño {real} bytes, se esperaban {esperado}"),
            FalloVerificacion::Estructura(m) => write!(f, "archivo incompleto o dañado: {m}"),
            FalloVerificacion::Lectura(m) => write!(f, "error de lectura: {m}"),
        }
    }
}

fn lectura(e: std::io::Error) -> FalloVerificacion {
    FalloVerificacion::Lectura(e.to_string())
}

/// Devuelve el SHA-256 en hexadecimal si el archivo pasa todas las comprobaciones.
pub fn verificar_archivo(ruta: &Path, tamano_esperado: u64, extension: &str) -> Result<String, FalloVerificacion> {
    let meta = std::fs::metadata(ruta).map_err(|_| FalloVerificacion::NoExiste)?;
    if meta.len() != tamano_esperado {
        return Err(FalloVerificacion::Tamano { esperado: tamano_esperado, real: meta.len() });
    }
    let mut f = File::open(ruta).map_err(lectura)?;
    comprobar_estructura(&mut f, meta.len(), extension)?;
    f.seek(SeekFrom::Start(0)).map_err(lectura)?;
    let mut h = Sha256::new();
    let mut buf = vec![0u8; 1 << 20];
    loop {
        let n = f.read(&mut buf).map_err(lectura)?;
        if n == 0 {
            break;
        }
        h.update(&buf[..n]);
    }
    Ok(hex::encode(h.finalize()))
}

pub fn comprobar_estructura<R: Read + Seek>(f: &mut R, len: u64, extension: &str) -> Result<(), FalloVerificacion> {
    match extension.to_ascii_uppercase().as_str() {
        "JPG" | "JPEG" => jpeg(f, len),
        "PNG" => png(f, len),
        "HEIC" | "HEIF" | "MOV" | "MP4" | "M4V" | "AVIF" | "3GP" => isobmff(f, len),
        _ => Ok(()),
    }
}

fn leer_en<R: Read + Seek>(f: &mut R, pos: u64, n: usize) -> Result<Vec<u8>, FalloVerificacion> {
    f.seek(SeekFrom::Start(pos)).map_err(lectura)?;
    let mut v = vec![0u8; n];
    f.read_exact(&mut v).map_err(lectura)?;
    Ok(v)
}

fn jpeg<R: Read + Seek>(f: &mut R, len: u64) -> Result<(), FalloVerificacion> {
    if len < 4 || leer_en(f, 0, 2)? != [0xFF, 0xD8] {
        return Err(FalloVerificacion::Estructura("no empieza como JPEG".into()));
    }
    let cola = len.min(4096);
    let fin = leer_en(f, len - cola, cola as usize)?;
    if fin.windows(2).any(|w| w == [0xFF, 0xD9]) {
        Ok(())
    } else {
        Err(FalloVerificacion::Estructura("JPEG sin marcador de fin".into()))
    }
}

fn png<R: Read + Seek>(f: &mut R, len: u64) -> Result<(), FalloVerificacion> {
    const FIRMA: [u8; 8] = [0x89, b'P', b'N', b'G', 0x0D, 0x0A, 0x1A, 0x0A];
    const IEND: [u8; 12] = [0, 0, 0, 0, b'I', b'E', b'N', b'D', 0xAE, 0x42, 0x60, 0x82];
    if len < 20 || leer_en(f, 0, 8)? != FIRMA {
        return Err(FalloVerificacion::Estructura("no empieza como PNG".into()));
    }
    if leer_en(f, len - 12, 12)? != IEND {
        return Err(FalloVerificacion::Estructura("PNG sin bloque IEND final".into()));
    }
    Ok(())
}

fn isobmff<R: Read + Seek>(f: &mut R, len: u64) -> Result<(), FalloVerificacion> {
    let mut pos = 0u64;
    let mut primera = true;
    while pos < len {
        if len - pos < 8 {
            return Err(FalloVerificacion::Estructura(format!("caja truncada en el byte {pos}")));
        }
        let h = leer_en(f, pos, 8)?;
        let tam32 = u32::from_be_bytes([h[0], h[1], h[2], h[3]]);
        let tipo = &h[4..8];
        if !tipo.iter().all(|b| b.is_ascii_graphic() || *b == b' ') {
            return Err(FalloVerificacion::Estructura(format!("tipo de caja inválido en el byte {pos}")));
        }
        if primera && !matches!(tipo, b"ftyp" | b"wide" | b"free" | b"skip" | b"mdat" | b"moov" | b"pnot") {
            return Err(FalloVerificacion::Estructura("no empieza como HEIC/MOV/MP4".into()));
        }
        primera = false;
        let tam = match tam32 {
            0 => len - pos,
            1 => {
                if len - pos < 16 {
                    return Err(FalloVerificacion::Estructura(format!("caja grande truncada en el byte {pos}")));
                }
                let g = leer_en(f, pos + 8, 8)?;
                u64::from_be_bytes([g[0], g[1], g[2], g[3], g[4], g[5], g[6], g[7]])
            }
            n => n as u64,
        };
        if tam < 8 {
            return Err(FalloVerificacion::Estructura(format!("tamaño de caja inválido en el byte {pos}")));
        }
        pos = pos.checked_add(tam).ok_or_else(|| FalloVerificacion::Estructura("tamaño de caja desbordado".into()))?;
    }
    if pos != len {
        return Err(FalloVerificacion::Estructura(format!("el archivo está cortado: la última caja termina en {pos} y el archivo mide {len}")));
    }
    Ok(())
}
```

```rust
  sha256 = CASE WHEN partes.tamano <> excluded.tamano OR partes.extension <> excluded.extension THEN NULL ELSE partes.sha256 END,
  intentos = CASE WHEN partes.tamano <> excluded.tamano OR partes.extension <> excluded.extension THEN 0 ELSE partes.intentos END,
  proximo_intento = CASE WHEN partes.tamano <> excluded.tamano OR partes.extension <> excluded.extension THEN 0 ELSE partes.proximo_intento END,

/// (estado, segundos de espera) tras `intentos` fallos consecutivos.
pub fn espera_reintento(intentos: u32) -> (&'static str, i64) {
    const ESPERAS: [i64; 9] = [5, 30, 120, 300, 600, 1200, 1800, 3600, 3600];
    if intentos >= 10 {
        ("error", 6 * 3600)
    } else {
        ("pendiente", ESPERAS[(intentos.max(1) - 1) as usize])
    }
}

fn tipo_de(s: String) -> TipoParte {

impl Registro {
    pub fn abrir(ruta: &Path) -> Result<Registro> {
        if let Some(p) = ruta.parent() {
            std::fs::create_dir_all(p)?;
        }
        let con = Connection::open(ruta).with_context(|| format!("abriendo {}", ruta.display()))?;
        con.busy_timeout(Duration::from_secs(30))?;
        // journal_mode devuelve una fila: se ejecuta con query_row para no provocar "Execute returned results".
        con.query_row("PRAGMA journal_mode=WAL", [], |_| Ok(()))?;
        con.execute_batch("PRAGMA synchronous=FULL;")?;
        Self::con_esquema(con)
    }

    pub fn en_memoria() -> Result<Registro> {
        Self::con_esquema(Connection::open_in_memory()?)
    }

        con.execute_batch(ESQUEMA)?;
        Ok(Registro { con })
    }

    pub fn upsert_asset(&mut self, a: &AssetIcloud, marca: i64) -> Result<()> {
        let f = layout::fecha(&a.fecha).with_context(|| format!("fecha inválida en {}", a.id))?;
        let tx = self.con.transaction()?;
        tx.execute(
            "INSERT INTO assets(id, biblioteca, nombre_base, fecha, fecha_unix, mes, visto_en_lista) VALUES(?1, ?2, ?3, ?4, ?5, ?6, ?7)
             ON CONFLICT(id) DO UPDATE SET biblioteca = excluded.biblioteca, nombre_base = excluded.nombre_base,
               fecha = excluded.fecha, fecha_unix = excluded.fecha_unix, mes = excluded.mes,
               visto_en_lista = excluded.visto_en_lista, borrado_icloud = NULL",

            tx.execute(UPSERT_PARTE, params![a.id, p.tipo.como_str(), p.extension, p.tamano as i64, p.checksum, p.url])?;

        tx.commit()?;
        Ok(())
```

```rust
pub fn servidor(rutas: Vec<(&str, Comportamiento)>) -> Servidor {
    let listener = TcpListener::bind("127.0.0.1:0").unwrap();
    let base = format!("http://{}", listener.local_addr().unwrap());
    let mapa: HashMap<String, Comportamiento> = rutas.into_iter().map(|(r, c)| (r.to_string(), c)).collect();
    let peticiones = Arc::new(Mutex::new(Vec::new()));
    let registro = peticiones.clone();
    std::thread::spawn(move || {
        let mut cortadas: HashMap<String, bool> = HashMap::new();
        for stream in listener.incoming() {
            if let Ok(s) = stream {
                atender(s, &mapa, &registro, &mut cortadas);
            }
        }
    });
    Servidor { base, peticiones }
}

fn atender(mut stream: TcpStream, mapa: &HashMap<String, Comportamiento>, peticiones: &Mutex<Vec<Peticion>>, cortadas: &mut HashMap<String, bool>) {
    let mut lector = BufReader::new(stream.try_clone().unwrap());
    let mut primera = String::new();
    if lector.read_line(&mut primera).is_err() {
        return;
    }
    let ruta = primera.split_whitespace().nth(1).unwrap_or("/").to_string();
    let mut rango = None;
    loop {
        let mut l = String::new();
        if lector.read_line(&mut l).unwrap_or(0) == 0 {
            break;
        }
        let l = l.trim_end();
        if l.is_empty() {
            break;
        }
        if let Some((k, v)) = l.split_once(':') {
            if k.eq_ignore_ascii_case("range") {
                rango = Some(v.trim().to_string());
            }
        }
    }
    peticiones.lock().unwrap().push(Peticion { ruta: ruta.clone(), rango: rango.clone() });
    let desde = rango
        .as_deref()
        .and_then(|r| r.strip_prefix("bytes="))
        .and_then(|r| r.split('-').next())
        .and_then(|n| n.parse::<usize>().ok())
        .unwrap_or(0);
    match mapa.get(&ruta) {
        None => {
            let _ = stream.write_all(b"HTTP/1.1 404 Not Found\r\nContent-Length: 0\r\nConnection: close\r\n\r\n");
        }
        Some(Comportamiento::Estado(c)) => {
            let _ = write!(stream, "HTTP/1.1 {c} X\r\nContent-Length: 0\r\nConnection: close\r\n\r\n");
        }
        Some(Comportamiento::Servir(datos)) => enviar(&mut stream, datos, desde, None),
        Some(Comportamiento::CortarPrimeraVez { datos, tras }) => {
            let primera_vez = cortadas.insert(ruta.clone(), true).is_none();
            enviar(&mut stream, datos, desde, if primera_vez { Some(*tras) } else { None });
        }
    }
    let _ = stream.flush();
    let _ = stream.shutdown(std::net::Shutdown::Both);
}

fn enviar(stream: &mut TcpStream, datos: &[u8], desde: usize, cortar_tras: Option<usize>) {
    let cuerpo = &datos[desde.min(datos.len())..];
    let cab = if desde > 0 {
        format!(
            "HTTP/1.1 206 Partial Content\r\nContent-Length: {}\r\nContent-Range: bytes {}-{}/{}\r\nConnection: close\r\n\r\n",
            cuerpo.len(), desde, datos.len() - 1, datos.len()
        )
    } else {
        format!("HTTP/1.1 200 OK\r\nContent-Length: {}\r\nConnection: close\r\n\r\n", cuerpo.len())
    };
    let _ = stream.write_all(cab.as_bytes());
    let n = cortar_tras.unwrap_or(cuerpo.len()).min(cuerpo.len());
    let _ = stream.write_all(&cuerpo[..n]);
}

pub fn patron(n: usize) -> Vec<u8> {
    (0..n).map(|i| (i % 251) as u8).collect()
}

pub fn caja(tipo: &[u8; 4], contenido: &[u8]) -> Vec<u8> {
    let mut v = ((8 + contenido.len()) as u32).to_be_bytes().to_vec();
    v.extend_from_slice(tipo);
    v.extend_from_slice(contenido);
    v
}
```

```rust
//! Descarga a <archivo>.part reanudando lo que ya hubiera (Range).
use reqwest::blocking::Client;
use reqwest::StatusCode;
use std::fs::OpenOptions;
use std::io::{Read, Write};
use std::path::{Path, PathBuf};
use std::sync::atomic::{AtomicBool, Ordering};
use std::time::Duration;

#[derive(Debug, Clone, PartialEq)]
pub enum ErrorDescarga {
    /// 401/403/404/410: hay que pedir enlaces nuevos a iCloud.
    UrlCaducada(u16),
    Transitorio(String),
    Disco(String),
    Cancelada,
}

impl std::fmt::Display for ErrorDescarga {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            ErrorDescarga::UrlCaducada(c) => write!(f, "enlace de descarga caducado (HTTP {c})"),
            ErrorDescarga::Transitorio(m) => write!(f, "fallo de red: {m}"),
            ErrorDescarga::Disco(m) => write!(f, "fallo de disco: {m}"),
            ErrorDescarga::Cancelada => write!(f, "cancelada"),
        }
    }
}

fn disco(e: std::io::Error) -> ErrorDescarga {
    ErrorDescarga::Disco(e.to_string())
}

pub fn cliente() -> Client {
    Client::builder()
        .connect_timeout(Duration::from_secs(30))
        .user_agent("icopia/0.1")
        .build()
        .expect("no pude crear el cliente HTTP")
}

pub fn ruta_part(final_: &Path) -> PathBuf {
    let mut s = final_.as_os_str().to_owned();
    s.push(".part");
    PathBuf::from(s)
}

fn inicio_content_range(v: &str) -> Option<u64> {
    v.strip_prefix("bytes ")?.split('-').next()?.parse().ok()
}

/// Deja en `part` exactamente `tamano` bytes descargados de `url`, reanudando si ya había algo.
pub fn descargar(cliente: &Client, url: &str, part: &Path, tamano: u64, cancelar: &AtomicBool) -> Result<(), ErrorDescarga> {
    let mut tengo = std::fs::metadata(part).map(|m| m.len()).unwrap_or(0);
    if tengo > tamano {
        std::fs::remove_file(part).map_err(disco)?;
        tengo = 0;
    }
    if tengo == tamano && tamano > 0 {
        return Ok(());
    }
    let segundos = 120 + tamano.saturating_sub(tengo) / (256 * 1024);
    let mut pet = cliente.get(url).timeout(Duration::from_secs(segundos));
    if tengo > 0 {
        pet = pet.header(reqwest::header::RANGE, format!("bytes={tengo}-"));
    }
    let mut resp = pet.send().map_err(|e| ErrorDescarga::Transitorio(format!("conexión: {e}")))?;
    let anexar = match resp.status() {
        StatusCode::PARTIAL_CONTENT => {
            let inicio = resp
                .headers()
                .get(reqwest::header::CONTENT_RANGE)
                .and_then(|v| v.to_str().ok())
                .and_then(inicio_content_range);
            if inicio != Some(tengo) {
                let _ = std::fs::remove_file(part);
                return Err(ErrorDescarga::Transitorio("el servidor devolvió un rango inesperado; se reinicia".into()));
            }
            true
        }
        StatusCode::OK => false,
        StatusCode::RANGE_NOT_SATISFIABLE => {
            let _ = std::fs::remove_file(part);
            return Err(ErrorDescarga::Transitorio("rango no satisfacible; se reinicia".into()));
        }
        s if s == StatusCode::UNAUTHORIZED || s == StatusCode::FORBIDDEN || s == StatusCode::NOT_FOUND || s == StatusCode::GONE => {
            return Err(ErrorDescarga::UrlCaducada(s.as_u16()));
        }
        s => return Err(ErrorDescarga::Transitorio(format!("HTTP {}", s.as_u16()))),
    };
    let mut archivo = if anexar {
        OpenOptions::new().append(true).open(part)
    } else {
        OpenOptions::new().create(true).write(true).truncate(true).open(part)
    }
    .map_err(disco)?;
    let mut buf = vec![0u8; 1 << 20];
    loop {
        if cancelar.load(Ordering::Relaxed) {
            let _ = archivo.sync_all();
            return Err(ErrorDescarga::Cancelada);
        }
        let n = match resp.read(&mut buf) {
            Ok(n) => n,
            Err(e) => {
                let _ = archivo.sync_all();
                return Err(ErrorDescarga::Transitorio(format!("lectura: {e}")));
            }
        };
        if n == 0 {
            break;
        }
        archivo.write_all(&buf[..n]).map_err(disco)?;
    }
    archivo.sync_all().map_err(disco)?;
    let final_len = std::fs::metadata(part).map_err(disco)?.len();
    if final_len != tamano {
        return Err(ErrorDescarga::Transitorio(format!("descarga incompleta: {final_len} de {tamano} bytes")));
    }
    Ok(())
}
```

```rust
use std::path::Path;

/// Margen que siempre se deja libre: 1 GiB.
pub const MARGEN: u64 = 1 << 30;

pub fn espacio_libre(ruta: &Path) -> std::io::Result<u64> {
    let ancho: Vec<u16> = ruta.as_os_str().encode_wide().chain(std::iter::once(0)).collect();
    let mut libre: u64 = 0;
    let ok = unsafe { GetDiskFreeSpaceExW(ancho.as_ptr(), &mut libre, std::ptr::null_mut(), std::ptr::null_mut()) };
    if ok == 0 {
        return Err(std::io::Error::last_os_error());
    }
    Ok(libre)
}

pub fn cabe(ruta: &Path, bytes: u64) -> bool {
    espacio_libre(ruta).map(|l| l >= bytes.saturating_add(MARGEN)).unwrap_or(false)
}
```

```rust
use std::fs::{File, OpenOptions, TryLockError};
use std::path::Path;

pub struct Cerrojo {
    _archivo: File,
}

fn abrir(dir_datos: &Path) -> std::io::Result<File> {
    std::fs::create_dir_all(dir_datos)?;
    OpenOptions::new().create(true).read(true).write(true).truncate(false).open(dir_datos.join("motor.lock"))
}

/// `Ok(None)` si otro proceso ya lo tiene.
pub fn intentar(dir_datos: &Path) -> std::io::Result<Option<Cerrojo>> {
    let f = abrir(dir_datos)?;
    match f.try_lock() {
        Ok(()) => Ok(Some(Cerrojo { _archivo: f })),
        Err(TryLockError::WouldBlock) => Ok(None),
        Err(TryLockError::Error(e)) => Err(e),
    }
}

/// Espera hasta conseguirlo.
pub fn esperar(dir_datos: &Path) -> std::io::Result<Cerrojo> {
    let f = abrir(dir_datos)?;
    f.lock()?;
    Ok(Cerrojo { _archivo: f })
}
```

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum FinRonda {
    Completa,
    Relistar,
    SesionCaducada,
    SinEspacio,
    DestinoAusente,
    Cancelada,

#[derive(Debug, Clone, PartialEq)]
pub struct ResultadoRonda {
    pub fin: FinRonda,
    pub listados: usize,
    pub verificadas: usize,
    pub fallidas: usize,
}

#[derive(Debug, Clone, PartialEq)]
pub enum Avance {

    Copiando { hechas: usize, total: usize, actual: String },

}

#[derive(Debug, Clone, PartialEq)]

    Interrumpido(FinRonda, usize),

#[derive(Debug)]
pub enum ErrorParte {

    Verificacion(FalloVerificacion),
    Ruta(String),
    Disco(String),

}

impl fmt::Display for ErrorParte {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            ErrorParte::Descarga(e) => write!(f, "{e}"),
            ErrorParte::Verificacion(e) => write!(f, "verificación: {e}"),
            ErrorParte::Ruta(m) => write!(f, "ruta: {m}"),
            ErrorParte::Disco(m) => write!(f, "disco: {m}"),
            ErrorParte::Cancelada => write!(f, "cancelada"),
        }
    }

pub fn ahora() -> i64 {
    chrono::Utc::now().timestamp()

fn resultado(fin: FinRonda, listados: usize) -> ResultadoRonda {
    ResultadoRonda { fin, listados, verificadas: 0, fallidas: 0 }

/// Lista iCloud y lo vuelca al registro. Solo guarda la marca si el listado terminó bien.
pub fn listar_en_registro(
    registro: &Mutex<Registro>,
    fuente: &mut dyn FuenteIcloud,
    cancelar: &AtomicBool,
    avance: &(dyn Fn(Avance) + Sync),
) -> anyhow::Result<Listado> {
    let marca = ahora();
    let mut error_registro: Option<anyhow::Error> = None;
    let mut vistos = 0usize;
    let r = fuente.listar(&mut |asset| {
        if cancelar.load(Ordering::Relaxed) {
            return false;
        }
        if let Err(e) = registro.lock().unwrap().upsert_asset(&asset, marca) {
            error_registro = Some(e);
            return false;
        }
        vistos += 1;
        if vistos % 200 == 0 {
            avance(Avance::Listando { vistos });
        }
        true
    });
    if let Some(e) = error_registro {
        return Err(e);
    }
    match r {
        Ok(_) => {
            registro.lock().unwrap().guardar_marca_lista(marca)?;
            avance(Avance::Listando { vistos });
            Ok(Listado::Completo(vistos))
        }
        Err(ErrorFuente::SesionCaducada) => Ok(Listado::Interrumpido(FinRonda::SesionCaducada, vistos)),
        Err(ErrorFuente::Cancelado) => Ok(Listado::Interrumpido(FinRonda::Cancelada, vistos)),
        Err(e) => Err(anyhow::anyhow!("listando iCloud: {e}")),
    }
}

pub fn ejecutar_ronda(
    destino: &Path,
    registro: &Mutex<Registro>,
    fuente: &mut dyn FuenteIcloud,
    http: &Client,
    op: &OpcionesRonda,
    cancelar: &AtomicBool,
    avance: &(dyn Fn(Avance) + Sync),
) -> anyhow::Result<ResultadoRonda> {
    if !destino.is_dir() {
        return Ok(resultado(FinRonda::DestinoAusente, 0));
    }
    let dir_datos = destino.join(".icopia");
    let listados = match listar_en_registro(registro, fuente, cancelar, avance)? {
        Listado::Completo(n) => n,
        Listado::Interrumpido(fin, n) => return Ok(resultado(fin, n)),
    };

    let trabajos = registro.lock().unwrap().partes_pendientes(ahora(), op.mes.as_deref())?;
    let total = trabajos.len();
    let cola = Mutex::new(VecDeque::from(trabajos));
    let hechas = AtomicUsize::new(0);
    let verificadas = AtomicUsize::new(0);
    let fallidas = AtomicUsize::new(0);
    let relistar = AtomicBool::new(false);
    let sin_espacio = AtomicBool::new(false);

    std::thread::scope(|s| {
        for _ in 0..op.concurrencia.max(1) {
            s.spawn(|| loop {
                if cancelar.load(Ordering::Relaxed) || relistar.load(Ordering::Relaxed) || sin_espacio.load(Ordering::Relaxed) {
                    break;
                }
                let Some(t) = cola.lock().unwrap().pop_front() else { break };
                if !disco::cabe(destino, t.tamano) {
                    sin_espacio.store(true, Ordering::Relaxed);
                    break;
                }
                match procesar_parte(destino, registro, http, &t, cancelar) {
                    Ok(sha) => {
                        if let Err(e) = registro.lock().unwrap().marcar_verificada(&t.asset_id, t.tipo, &sha) {
                            bitacora::escribir(&dir_datos, &format!("ERROR registro {}: {e:#}", t.asset_id));
                        }
                        verificadas.fetch_add(1, Ordering::Relaxed);
                    }
                    Err(ErrorParte::Cancelada) => break,
                    Err(e) => {
                        if matches!(e, ErrorParte::Descarga(ErrorDescarga::UrlCaducada(_))) {
                            relistar.store(true, Ordering::Relaxed);
                        }
                        let msg = e.to_string();
                        bitacora::escribir(&dir_datos, &format!("FALLO {} {} ({}): {msg}", t.nombre_base, t.tipo.como_str(), t.asset_id));
                        let _ = registro.lock().unwrap().registrar_fallo(&t.asset_id, t.tipo, &msg, ahora());
                        fallidas.fetch_add(1, Ordering::Relaxed);
                    }
                }
                let n = hechas.fetch_add(1, Ordering::Relaxed) + 1;
                avance(Avance::Copiando { hechas: n, total, actual: format!("{} ({})", t.nombre_base, t.tipo.como_str()) });
            });
        }
    });

    let fin = if cancelar.load(Ordering::Relaxed) {
        FinRonda::Cancelada
    } else if sin_espacio.load(Ordering::Relaxed) {
        FinRonda::SinEspacio
    } else if relistar.load(Ordering::Relaxed) {
        FinRonda::Relistar
    } else {
        FinRonda::Completa
    };
    Ok(ResultadoRonda {
        fin,
        listados,
        verificadas: verificadas.load(Ordering::Relaxed),
        fallidas: fallidas.load(Ordering::Relaxed),
    })
}

fn procesar_parte(destino: &Path, registro: &Mutex<Registro>, http: &Client, t: &TrabajoParte, cancelar: &AtomicBool) -> Result<String, ErrorParte> {
    let rel = match &t.ruta {
        Some(r) => r.clone(),
        None => {
            let mut reg = registro.lock().unwrap();
            let rel = {
                let consulta = &*reg;
                layout::elegir_ruta(&t.nombre_base, &t.asset_id, &t.fecha, t.tipo, &t.extension, &mut |clave| {
                    consulta.ruta_ocupada(clave).unwrap_or(true) || destino.join(clave).exists()
                })
                .map_err(|e| ErrorParte::Ruta(e.to_string()))?
            };
            reg.asignar_ruta(&t.asset_id, t.tipo, &rel).map_err(|e| ErrorParte::Ruta(e.to_string()))?;
            rel
        }
    };
    let final_ = destino.join(&rel);
    if let Some(p) = final_.parent() {
        std::fs::create_dir_all(p).map_err(|e| ErrorParte::Disco(e.to_string()))?;
    }
    // Recuperación tras un corte entre "renombrar" y "anotar como verificado".
    if final_.exists() {
        if let Ok(sha) = verificar::verificar_archivo(&final_, t.tamano, &t.extension) {
            return Ok(sha);
        }
    }
    let part = descarga::ruta_part(&final_);
    descarga::descargar(http, &t.url, &part, t.tamano, cancelar).map_err(|e| match e {
        ErrorDescarga::Cancelada => ErrorParte::Cancelada,
        otro => ErrorParte::Descarga(otro),
    })?;
    match verificar::verificar_archivo(&part, t.tamano, &t.extension) {
        Ok(sha) => {
            std::fs::rename(&part, &final_).map_err(|e| ErrorParte::Disco(e.to_string()))?;
            Ok(sha)
        }
        Err(f) => {
            let _ = std::fs::remove_file(&part);
            Err(ErrorParte::Verificacion(f))
        }
    }
}
```

```rust
//! "Verificar todo": re-comprueba lo copiado y reprograma lo dañado o ausente.
use crate::registro::Registro;
use crate::verificar;
use std::path::Path;
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Mutex;

#[derive(Debug, Default, Clone, PartialEq)]
pub struct ResultadoVerificacion {
    pub revisadas: usize,
    /// (ruta relativa, motivo)
    pub malas: Vec<(String, String)>,
}

pub fn verificar_todo(
    destino: &Path,
    registro: &Mutex<Registro>,
    cancelar: &AtomicBool,
    avance: &dyn Fn(usize, usize),
) -> anyhow::Result<ResultadoVerificacion> {
    let partes = registro.lock().unwrap().partes_verificadas()?;
    let total = partes.len();
    let mut r = ResultadoVerificacion::default();
    for p in &partes {
        if cancelar.load(Ordering::Relaxed) {
            break;
        }
        let motivo = match verificar::verificar_archivo(&destino.join(&p.ruta), p.tamano, &p.extension) {
            Ok(sha) if sha == p.sha256 => None,
            Ok(_) => Some("el contenido cambió (SHA-256 distinto)".to_string()),
            Err(f) => Some(f.to_string()),
        };
        if let Some(m) = motivo {
            registro.lock().unwrap().marcar_para_redescarga(&p.asset_id, p.tipo, &m)?;
            r.malas.push((p.ruta.clone(), m));
        }
        r.revisadas += 1;
        avance(r.revisadas, total);
    }
    Ok(r)
}
```

```rust
use crate::fuente::FuenteIcloud;
use crate::registro::{Candidato, Registro};
use crate::verificar;

use std::io::Write;
use std::path::Path;

pub const TAMANO_LOTE: usize = 50;

#[derive(Debug, Clone, PartialEq)]
pub struct PlanLiberar {
    pub listos: Vec<Candidato>,
    pub excluidos: Vec<(Candidato, String)>,
    pub no_verificados: u64,
    pub bytes: u64,
}

#[derive(Debug, Clone, PartialEq)]
pub struct ResumenBorrado {
    pub borrados: usize,
    pub fallidos: Vec<(String, String)>,
}

/// Requiere un listado completo reciente (`marca_lista`): solo propone lo que sigue en iCloud.
pub fn preparar(destino: &Path, registro: &Mutex<Registro>, mantener_dias: u32, ahora: i64, avance: &dyn Fn(usize, usize)) -> Result<PlanLiberar> {
    let (candidatos, no_verificados) = {
        let reg = registro.lock().unwrap();
        let marca = reg.marca_lista()?.ok_or_else(|| anyhow!("No hay un listado completo de iCloud; no se puede liberar"))?;
        reg.candidatos_liberar(marca, ahora - i64::from(mantener_dias) * 86_400)?
    };
    let total = candidatos.len();
    let mut plan = PlanLiberar { listos: vec![], excluidos: vec![], no_verificados, bytes: 0 };
    for (i, c) in candidatos.into_iter().enumerate() {
        match motivo_exclusion(destino, &c) {
            None => {
                plan.bytes += c.partes.iter().map(|p| p.tamano).sum::<u64>();
                plan.listos.push(c);
            }
            Some(m) => plan.excluidos.push((c, m)),
        }
        avance(i + 1, total);
    }
    Ok(plan)
}

fn motivo_exclusion(destino: &Path, c: &Candidato) -> Option<String> {
    for p in &c.partes {
        match verificar::verificar_archivo(&destino.join(&p.ruta), p.tamano, &p.extension) {
            Ok(sha) if sha == p.sha256 => {}
            Ok(_) => return Some(format!("{}: el contenido cambió (SHA-256 distinto)", p.ruta)),
            Err(f) => return Some(format!("{}: {f}", p.ruta)),
        }
    }
    None
}

pub fn ejecutar(destino: &Path, registro: &Mutex<Registro>, fuente: &mut dyn FuenteIcloud, listos: &[Candidato], avance: &dyn Fn(usize, usize)) -> Result<ResumenBorrado> {
    let csv = destino.join(".icopia").join("borrados.csv");
    let mut resumen = ResumenBorrado { borrados: 0, fallidos: vec![] };
    let mut hechos = 0;
    for lote in listos.chunks(TAMANO_LOTE) {
        let ids: Vec<String> = lote.iter().map(|c| c.asset_id.clone()).collect();
        let r = fuente.borrar(&ids).map_err(|e| anyhow!("borrando en iCloud: {e}"))?;
        let cuando = chrono::Local::now().to_rfc3339();
        for id in &r.borrados {
            let Some(c) = lote.iter().find(|c| &c.asset_id == id) else { continue };
            registro.lock().unwrap().marcar_borrado(id, &cuando)?;
            anotar_csv(&csv, &cuando, c)?;
            resumen.borrados += 1;
        }
        resumen.fallidos.extend(r.fallidos);
        hechos += lote.len();
        avance(hechos, listos.len());
    }
    Ok(resumen)
}

fn campo(s: &str) -> String {
    format!("\"{}\"", s.replace('"', "\"\""))
}

fn anotar_csv(csv: &Path, cuando: &str, c: &Candidato) -> Result<()> {
    if let Some(p) = csv.parent() {
        std::fs::create_dir_all(p)?;
    }
    let nuevo = !csv.exists();
    let mut f = std::fs::OpenOptions::new().create(true).append(true).open(csv)?;
    if nuevo {
        writeln!(f, "fecha_borrado,asset_id,nombre,fecha_captura,archivos")?;

    let archivos: Vec<&str> = c.partes.iter().map(|p| p.ruta.as_str()).collect();
    writeln!(f, "{},{},{},{},{}", campo(cuando), campo(&c.asset_id), campo(&c.nombre_base), campo(&c.fecha), campo(&archivos.join(" | ")))?;
    f.sync_all()?;
    Ok(())
}
```

```rust
pub fn rgba(color: Color) -> (Vec<u8>, u32, u32) {

        Color::Rojo => (220, 40, 40),

        }
    }
    (v, N, N)
```

```rust
use crate::auditoria;
use crate::bandeja::estado::{EstadoUi, EventoUi, Fase};
use crate::bitacora;
use crate::cerrojo;
use crate::config::Config;
use crate::descarga;
use crate::energia::SinSuspension;
use crate::fuente::FuenteIcloud;
use crate::motor::{self, Avance, FinRonda, OpcionesRonda};
use crate::planificador;
use crate::registro::Registro;
use reqwest::blocking::Client;
use std::path::Path;
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::mpsc::{Receiver, RecvTimeoutError};
use std::sync::{Arc, Mutex};
use std::thread::JoinHandle;
use std::time::Duration;

#[derive(Debug, Clone, PartialEq)]
pub enum Orden {
    CopiarAhora,
    Pausar,
    Reanudar,
    Verificar,
    Salir,
}

pub type CargarConfig = Box<dyn Fn() -> Config + Send>;
pub type AbrirFuente = Box<dyn Fn(&Config) -> anyhow::Result<Box<dyn FuenteIcloud>> + Send>;
pub type Emitir = Box<dyn Fn(EventoUi) + Send + Sync>;

pub fn lanzar(rx: Receiver<Orden>, cancelar: Arc<AtomicBool>, cargar_config: CargarConfig, abrir_fuente: AbrirFuente, emitir: Emitir) -> JoinHandle<()> {
    std::thread::spawn(move || bucle(rx, &cancelar, &*cargar_config, &*abrir_fuente, &*emitir))
}

fn aviso(emitir: &(dyn Fn(EventoUi) + Sync), texto: impl Into<String>) {
    emitir(EventoUi::Aviso { titulo: "icopia".into(), texto: texto.into() });
}

fn abrir_registro(destino: &Path) -> anyhow::Result<Registro> {
    Registro::abrir(&destino.join(".icopia").join("registro.db"))
}

fn emitir_resumen(cfg: &Config, fase: Fase, emitir: &(dyn Fn(EventoUi) + Sync)) {
    let resumen = cfg
        .destino
        .as_deref()
        .filter(|d| d.is_dir())
        .and_then(|d| abrir_registro(d).ok())
        .and_then(|r| r.resumen().ok())
        .unwrap_or_default();
    emitir(EventoUi::Estado(EstadoUi { fase, verificadas: resumen.verificadas, total: resumen.partes }));
}

fn bucle(
    rx: Receiver<Orden>,
    cancelar: &AtomicBool,
    cargar_config: &dyn Fn() -> Config,
    abrir_fuente: &dyn Fn(&Config) -> anyhow::Result<Box<dyn FuenteIcloud>>,
    emitir: &(dyn Fn(EventoUi) + Sync),
) {
    let http = descarga::cliente();
    let mut pausado = false;
    let mut espera: Option<Duration> = Some(Duration::ZERO);
    let mut ultimo_fin: Option<FinRonda> = None;
    emitir_resumen(&cargar_config(), Fase::Inactiva, emitir);
    loop {
        let orden = match espera {
            Some(d) => match rx.recv_timeout(d) {
                Ok(o) => Some(o),
                Err(RecvTimeoutError::Timeout) => None,
                Err(RecvTimeoutError::Disconnected) => return,
            },
            None => match rx.recv() {
                Ok(o) => Some(o),
                Err(_) => return,
            },
        };
        let mut forzar = false;
        match orden {
            Some(Orden::Salir) => return,
            Some(Orden::Pausar) => {
                pausado = true;
                espera = None;
                emitir_resumen(&cargar_config(), Fase::Pausada, emitir);
                continue;
            }
            Some(Orden::Reanudar) | Some(Orden::CopiarAhora) => {
                pausado = false;
                forzar = true;
            }
            Some(Orden::Verificar) => {
                verificar(&cargar_config(), cancelar, emitir);
                continue;
            }
            None => {}
        }
        if pausado {
            espera = None;
            continue;
        }
        cancelar.store(false, Ordering::SeqCst);
        espera = una_ronda(&cargar_config(), &http, cancelar, abrir_fuente, emitir, forzar, &mut ultimo_fin);
    }
}

fn una_ronda(
    cfg: &Config,
    http: &Client,
    cancelar: &AtomicBool,
    abrir_fuente: &dyn Fn(&Config) -> anyhow::Result<Box<dyn FuenteIcloud>>,
    emitir: &(dyn Fn(EventoUi) + Sync),
    forzar: bool,
    ultimo_fin: &mut Option<FinRonda>,
) -> Option<Duration> {
    let Some(destino) = cfg.destino.clone() else {
        emitir(EventoUi::Estado(EstadoUi::sin_datos(Fase::SinDestino)));
        return None;
    };
    if cfg.apple_id.is_none() {
        emitir(EventoUi::Estado(EstadoUi::sin_datos(Fase::SesionCaducada)));
        return None;
    }
    if !destino.is_dir() {
        emitir(EventoUi::Estado(EstadoUi::sin_datos(Fase::DestinoAusente)));
        return Some(Duration::from_secs(600));
    }
    let dir_datos = destino.join(".icopia");
    let _cerrojo = match cerrojo::intentar(&dir_datos) {
        Ok(Some(c)) => c,
        Ok(None) => return Some(Duration::from_secs(60)), // otro proceso (p. ej. "liberar") trabaja
        Err(e) => {
            emitir(EventoUi::Estado(EstadoUi::sin_datos(Fase::Error(e.to_string()))));
            return Some(Duration::from_secs(600));
        }
    };
    let registro = match abrir_registro(&destino) {
        Ok(r) => Mutex::new(r),
        Err(e) => {
            emitir(EventoUi::Estado(EstadoUi::sin_datos(Fase::Error(e.to_string()))));
            return Some(Duration::from_secs(600));
        }
    };
    if forzar {
        let _ = registro.lock().unwrap().reintentar_ya();
    }
    let _energia = SinSuspension::activar();
    let mut fuente = match abrir_fuente(cfg) {
        Ok(f) => f,
        Err(e) => {
            bitacora::escribir(&dir_datos, &format!("ERROR abriendo el puente: {e:#}"));
            emitir(EventoUi::Estado(EstadoUi::sin_datos(Fase::Error(e.to_string()))));
            return Some(Duration::from_secs(900));
        }
    };
    let base = registro.lock().unwrap().resumen().unwrap_or_default();
    let avance = |a: Avance| {
        let fase = match a {
            Avance::Listando { vistos } => Fase::Listando { vistos },
            Avance::Copiando { hechas, total, .. } => Fase::Copiando { hechas, total },
        };
        emitir(EventoUi::Estado(EstadoUi { fase, verificadas: base.verificadas, total: base.partes }));
    };
    let op = OpcionesRonda { concurrencia: cfg.concurrencia, mes: None };
    let r = motor::ejecutar_ronda(&destino, &registro, fuente.as_mut(), http, &op, cancelar, &avance);
    drop(fuente);
    let reg = registro.lock().unwrap();
    let resumen = reg.resumen().unwrap_or_default();
    let prox = reg.proximo_reintento(None).ok().flatten();
    let estado = |fase: Fase| EventoUi::Estado(EstadoUi { fase, verificadas: resumen.verificadas, total: resumen.partes });
    match r {
        Err(e) => {
            bitacora::escribir(&dir_datos, &format!("ERROR en la ronda: {e:#}"));
            emitir(estado(Fase::Error(e.to_string())));
            Some(Duration::from_secs(900))
        }
        Ok(r) => {
            bitacora::escribir(&dir_datos, &format!("RONDA {:?}: {} verificadas, {} fallidas", r.fin, r.verificadas, r.fallidas));
            if r.verificadas > 0 {
                aviso(emitir, format!("{} archivos nuevos copiados y verificados", r.verificadas));
            }
            let nuevo = *ultimo_fin != Some(r.fin);
            *ultimo_fin = Some(r.fin);
            let fase = match r.fin {
                FinRonda::Completa | FinRonda::Relistar => Fase::Inactiva,
                FinRonda::Cancelada => Fase::Pausada,
                FinRonda::SesionCaducada => {
                    if nuevo {
                        aviso(emitir, "La sesión de iCloud caducó. Menú del icono → Iniciar sesión en iCloud…");
                    }
                    Fase::SesionCaducada
                }
                FinRonda::SinEspacio => {
                    if nuevo {
                        aviso(emitir, format!("No queda espacio en {}", destino.display()));
                    }
                    Fase::SinEspacio
                }
                FinRonda::DestinoAusente => Fase::DestinoAusente,
            };
            emitir(estado(fase));
            planificador::espera_tras_ronda(&r, prox, motor::ahora(), cfg.intervalo_horas)
        }
    }
}

fn verificar(cfg: &Config, cancelar: &AtomicBool, emitir: &(dyn Fn(EventoUi) + Sync)) {
    let Some(destino) = cfg.destino.clone() else { return };
    let dir_datos = destino.join(".icopia");
    let Ok(Some(_cerrojo)) = cerrojo::intentar(&dir_datos) else {
        aviso(emitir, "Hay una copia en marcha; vuelve a intentarlo luego.");
        return;
    };
    let Ok(reg) = abrir_registro(&destino) else { return };
    let reg = Mutex::new(reg);
    cancelar.store(false, Ordering::SeqCst);
    let r = auditoria::verificar_todo(&destino, &reg, cancelar, &|h, t| {
        if h % 50 == 0 || h == t {
            emitir(EventoUi::Estado(EstadoUi::sin_datos(Fase::Verificando { hechas: h, total: t })));
        }
    });
    match r {
        Ok(res) if res.malas.is_empty() => aviso(emitir, format!("Verificación completa: {} archivos en perfecto estado", res.revisadas)),
        Ok(res) => {
            for (ruta, m) in &res.malas {
                bitacora::escribir(&dir_datos, &format!("DAÑADO {ruta}: {m}"));
            }
            aviso(emitir, format!("{} archivos dañados o ausentes; se volverán a descargar", res.malas.len()));
        }
        Err(e) => aviso(emitir, format!("No se pudo verificar: {e}")),
    }
    drop(reg);
    emitir_resumen(cfg, Fase::Inactiva, emitir);
}
```

```rust
use anyhow::Context;
use icopia::bandeja::estado::EventoUi;

fn instancia_unica() -> bool {
    use windows_sys::Win32::Foundation::{GetLastError, ERROR_ALREADY_EXISTS};
    use windows_sys::Win32::System::Threading::CreateMutexW;
    let nombre: Vec<u16> = "Local\\icopia-bandeja\0".encode_utf16().collect();
    unsafe {
        let h = CreateMutexW(std::ptr::null(), 0, nombre.as_ptr());
        !h.is_null() && GetLastError() != ERROR_ALREADY_EXISTS
    }
}

fn icono_de(color: icopia::bandeja::estado::Color) -> Icon {
    let (rgba, w, h) = icono::rgba(color);
    Icon::from_rgba(rgba, w, h).expect("icono válido")
}

/// Abre `icopia.exe <sub> --pausa` en una consola nueva, pausando la copia mientras tanto.
fn lanzar_consola(sub: &str, tx: &mpsc::Sender<Orden>, cancelar: &AtomicBool, ya_pausado: bool) {
    if !ya_pausado {
        cancelar.store(true, Ordering::SeqCst);
        let _ = tx.send(Orden::Pausar);
    }
    let exe = std::env::current_exe().expect("ruta del exe").with_file_name("icopia.exe");
    let sub = sub.to_string();
    let tx = tx.clone();
    std::thread::spawn(move || {
        use std::os::windows::process::CommandExt;
        let _ = std::process::Command::new(&exe).arg(&sub).arg("--pausa").creation_flags(0x0000_0010).status(); // CREATE_NEW_CONSOLE
        if !ya_pausado {
            let _ = tx.send(Orden::Reanudar);
        }
    });
}

fn main() {
    if !instancia_unica() {
        return;
    }
    let mut cfg = Config::cargar().unwrap_or_default();
    if cfg.destino.is_none() {
        if let Some(p) = rfd::FileDialog::new().set_title("icopia: elige dónde guardar las fotos").pick_folder() {
            cfg.destino = Some(p);
            let _ = cfg.guardar();
        }
    }

    let event_loop = EventLoopBuilder::<EventoUi>::with_user_event().build();
    let proxy = Mutex::new(event_loop.create_proxy());
    let (tx, rx) = mpsc::channel::<Orden>();
    let cancelar = Arc::new(AtomicBool::new(false));
    hilo_motor::lanzar(
        rx,
        cancelar.clone(),
        Box::new(|| Config::cargar().unwrap_or_default()),
        Box::new(|cfg: &Config| {
            let id = cfg.apple_id.as_deref().context("sin Apple ID")?;
            Ok(Box::new(Puente::iniciar(id, &config::dir_sesion(), &config::log_puente())?) as Box<dyn FuenteIcloud>)
        }),
        Box::new(move |e| {
            let _ = proxy.lock().unwrap().send_event(e);
        }),
    );

    let i_estado = MenuItem::new("icopia — iniciando…", false, None);
    let i_copiar = MenuItem::new("Copiar ahora", true, None);
    let i_pausa = MenuItem::new("Pausar", true, None);
    let i_verificar = MenuItem::new("Verificar todo", true, None);
    let i_liberar = MenuItem::new("Liberar espacio en iCloud…", true, None);
    let i_abrir = MenuItem::new("Abrir carpeta de fotos", true, None);
    let i_destino = MenuItem::new("Cambiar destino…", true, None);
    let i_login = MenuItem::new("Iniciar sesión en iCloud…", true, None);
    let i_auto = CheckMenuItem::new("Iniciar con Windows", true, autoarranque::activo(), None);
    let i_salir = MenuItem::new("Salir", true, None);
    let menu = Menu::new();
    menu.append_items(&[
        &i_estado,
        &PredefinedMenuItem::separator(),
        &i_copiar,
        &i_pausa,
        &i_verificar,
        &i_liberar,
        &PredefinedMenuItem::separator(),
        &i_abrir,
        &i_destino,
        &i_login,
        &i_auto,
        &PredefinedMenuItem::separator(),
        &i_salir,
    ])
    .expect("menú");

    let mut menu_pendiente = Some(menu);
    let mut tray: Option<TrayIcon> = None;
    let mut pausado = false;

    event_loop.run(move |event, _, control_flow| {
        *control_flow = ControlFlow::WaitUntil(Instant::now() + Duration::from_millis(200));
        match event {
            Event::NewEvents(StartCause::Init) => {
                tray = Some(
                    TrayIconBuilder::new()
                        .with_menu(Box::new(menu_pendiente.take().expect("menú")))
                        .with_tooltip("icopia")
                        .with_icon(icono_de(icopia::bandeja::estado::Color::Gris))
                        .build()
                        .expect("icono de bandeja"),

            Event::UserEvent(EventoUi::Estado(e)) => {

                    cancelar.store(true, Ordering::SeqCst);
                    let _ = tx.send(Orden::Pausar);
                }
            } else if id == *i_verificar.id() {
                let _ = tx.send(Orden::Verificar);
            } else if id == *i_liberar.id() {
                lanzar_consola("liberar", &tx, &cancelar, pausado);
            } else if id == *i_login.id() {
                lanzar_consola("login", &tx, &cancelar, pausado);
            } else if id == *i_abrir.id() {
                if let Some(d) = Config::cargar().ok().and_then(|c| c.destino) {
                    let _ = std::process::Command::new("explorer").arg(d).spawn();

            } else if id == *i_destino.id() {

            } else if id == *i_salir.id() {
                cancelar.store(true, Ordering::SeqCst);
                let _ = tx.send(Orden::Salir);
                tray.take();
                *control_flow = ControlFlow::Exit;
            }
        }
    });
}
```
