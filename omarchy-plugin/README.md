# Omarchy plugin (source mirror)

Marketplace listing requires a **separate public repository** with `manifest.json` at the repo root ([Publish guide](https://plugins.omarchy.org/publish.html)):

**https://github.com/hljghost/omarchy-icdown-plugin**

- Plugin id: `io.github.hljghost.icdown`
- Install: `omarchy plugin add https://github.com/hljghost/omarchy-icdown-plugin.git --enable`

This directory mirrors that plugin for in-tree development.
